# AI Debate Bot

مشروع لتطوير بوت جدلي باستخدام الذكاء الاصطناعي. 
هدفه إنشاء نقاشات منطقية ومثيرة باستخدام خوارزميات الذكاء الاصطناعي.

## كيفية الاستخدام:
1. كل ما عليك هو تشغيل الكود في بيئة تدعم Node.js.
2. استخدم المكتبات مثل `openai` أو `tensorflow` لتوسيع إمكانيات البوت.
